# 图书情报检索与统计平台 技术文档

---

## 一、项目概述

### 1. 项目背景

某高校图书馆拟建设图书情报检索与统计平台，用于管理馆藏图书与读者借阅记录，并提供多维度检索与统计服务。本项目基于 MongoDB 数据库完成从环境部署、数据建模、检索功能、统计报表到应用程序开发的完整流程。

### 2. 业务目标

- 实现图书、读者、借阅流水三类数据的存储与管理
- 提供精确查询、范围查询、组合条件查询等多种检索方式
- 支持分类统计、借阅趋势、热门排行等聚合分析
- 开发菜单式命令行应用，方便日常使用

### 3. 组内分工（三人小组）

- 同学 A：负责任务一、二 —— 环境部署与数据建模
- 同学 B：负责任务三、四 —— 检索功能与统计权限
- 同学 C：负责任务五、六 —— 程序开发与验收交付

## 二、环境与数据建模

### 1. 部署关键参数

- MongoDB 版本：社区版 6.0+
- 服务端口：27017（默认）
- 数据目录：自定义创建（如 D:\mongodb\data）
- Python 版本：3.9+，驱动：pymongo

### 2. 四个业务集合设计

| 集合名 | 用途 | 核心字段 |
|---|---|---|
| books | 图书信息 | isbn, title, author, category, price, stock, rating, tags |
| readers | 读者信息 | card_no, name, college, level, email, phone |
| borrow_logs | 借阅流水 | borrow_date, return_date, reader_card, book_isbn, status |
| category_stats | 统计结果 | _id(类别), book_count, avg_rating |

### 3. 三种特殊集合实现方式

- **固定集合 book_logs**：capped 模式，大小 1MB，最多 1000 条，自动淘汰旧数据
- **时间序列集合 borrow_logs**：timeField 设为 borrow_date，granularity 设为 hours，2 年自动过期
- **视图 book_in_stock**：基于 books 集合，管道过滤 stock > 0 的图书

### 4. 索引设计

- 唯一索引：books.isbn（防止重复 ISBN）
- 单键索引：books.title、books.category
- 多键索引：books.tags
- 复合索引：(category, price) 加速分类+价格联合查询

## 三、功能实现

### 1. 检索功能（任务三）

实现了 16 条查询操作，覆盖基础检索（$gt、$lt、$eq、$ne、$in）、组合检索（$and、$or、$regex、$all、$size、$exists）以及结果处理（$type、sort+limit、投影、distinct）。

同时实现了 7 条更新删除操作，包括 $inc 增减库存、$mul 批量打折、$currentDate 记录时间、$unset 删除字段，以及 deleteOne / deleteMany / replaceOne。

### 2. 统计分析（任务四）

使用聚合管道完成 9 项统计：

- 按类别分组统计数量与平均评分（$group + $sum + $avg）
- 出版社 Top5（$group + $sort + $limit）
- sortByCount 找文档数最多类别
- 评分最高 3 本（$sort + $limit + $project）
- 销售额计算（$multiply + $round）
- 按年份格式化借阅趋势（$dateToString）
- 读者借阅次数排行
- $lookup 关联学院借阅量
- $merge 写入统计集合

### 3. 权限管理

创建了两个账号：libReader（只读角色）和 libWriter（readWrite + dbAdmin 角色）。启用访问控制后，只读账号无法执行写操作，验证了权限隔离效果。

### 4. Python 应用程序（任务五）

采用模块化设计，共 6 个文件：

- **mongodb_connect.py**：连接封装，统一管理连接参数
- **book_manager.py**：图书增删改查、条件检索、评分排行
- **reader_manager.py**：读者信息管理、学院统计、等级分布
- **borrow_manager.py**：借阅登记、归还处理、逾期查询
- **stat_manager.py**：分类统计、借阅趋势、畅销榜（聚合管道）
- **main.py**：菜单主程序，串联各模块

主程序启动时显示连接状态和各集合文档数，菜单包含 8 个功能项，覆盖检索、统计、更新、删除，操作后打印受影响文档数。

## 四、问题与核对

### 1. 调试难点与排查

**难点一：时间序列集合创建失败**

- 问题：第一次创建 borrow_logs 时间序列集合时报错。
- 原因：集合名已经存在（之前先建了普通集合）。
- 解决：先 `db.borrow_logs.drop()` 删除旧集合，再按时间序列参数重新创建。

**难点二：$lookup 关联查不到数据**

- 问题：关联 readers 和 borrow_logs 时结果为空。
- 原因：reader_card 字段类型不一致。
- 解决：确认两边都是字符串类型后，$lookup 正常返回结果。

### 2. 命令行与 Compass 结果核对

用 Compass 连接同一实例，逐项核对：

- Q1 定价 80 元以上：命令行结果与 Compass 一致 ✓
- Q2 库存不足 10 本：命令行结果与 Compass 一致 ✓
- Q14 评分前 5：命令行排序与 Compass 一致 ✓
- A1 分类统计：各分类数量与聚合结果一致 ✓
- 视图 book_in_stock：数量等于 stock > 0 的图书数 ✓
